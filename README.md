# Devfolio Starter

A responsive, dark-themed developer portfolio built with plain HTML, CSS, and JavaScript.

## Repository name
`devfolio-starter`

## Features
- Responsive layout for desktop and mobile
- Code-terminal hero section
- About, project, skills, and contact sections
- Mobile navigation menu
- No frameworks, package installs, or virtual environment required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

Optional: use the VS Code **Live Server** extension for automatic refresh while editing.

## Customize before publishing
1. Replace `Yuvi` / `yuvi.dev` with your preferred display name.
2. Update the sample projects with projects you have actually built.
3. Replace the GitHub profile URL and `hello@example.com` with your real links.
4. Update the skills to match what you know.

## Publish on GitHub
1. Create a new GitHub repository named `devfolio-starter`.
2. Upload the files in this folder (not the ZIP file itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

Your site should appear at `https://YOUR-USERNAME.github.io/devfolio-starter/` after GitHub Pages finishes deploying.
